# SuperDaily – Version 11 · 7. November 2026

## Neu
- **Routinen vorgeben:** Simon kann Irina eine Routine vorgeben und umgekehrt. Beim Anlegen stehen unter „Für wen“ jetzt für beide alle vier Möglichkeiten: Simon, Irina, Beide einzeln, Gemeinsam.
- An vorgegebenen Routinen steht **„vorgegeben von Simon“** bzw. **„vorgegeben von Irina“**, auf „Heute“ und unter „Routinen“. Bei Routinen, die man für sich selbst anlegt, steht nichts.
- **Hinweise auf „Heute“:** Hat die andere Person seit deinem letzten Blick eine Aufgabe vergeben oder eine Routine vorgegeben, erscheint z. B. „2 neue Aufgaben von Irina“ oder „1 neue Routine von Simon“. Antippen öffnet den passenden Tab; das X schließt den Hinweis.

## Geändert
- Beide dürfen alle Routinen bearbeiten, archivieren und wiederherstellen, auch die der anderen Person. Das Schloss-Symbol unter „Routinen“ entfällt.
- Vergangene Tage bleiben so gewertet, wie sie geplant waren – auch wenn die andere Person eine Routine ändert.

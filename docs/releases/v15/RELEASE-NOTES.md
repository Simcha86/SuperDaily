# SuperDaily – Version 15 · 17. November 2026

## Neu
- **Ausgaben: Kategorie beim Eintragen wählen.** Unter dem Eingabefeld steht eine Leiste mit allen Kategorien. Beim Tippen markiert die App ihren Vorschlag; ein Tipp auf eine andere Kategorie gilt stattdessen.
- **Zurück-Taste am Handy:** Sie schließt zuerst ein offenes Fenster, dann eine Unterseite und führt dann zu „Heute“. Erst auf „Heute“ verlässt sie die App.

## Geändert
- Jede Ausgabe zeigt einen Stift. Antippen öffnet das Bearbeiten: Betrag, Geschäft, Kategorie, Datum, Notiz ändern oder die Ausgabe löschen.
- Nach dem Eintragen zeigt die App, was gespeichert wurde, mit Betrag und Kategorie.

## Vor dem Update zu tun
- Nichts. Die Firebase-Regeln ändern sich nicht.
